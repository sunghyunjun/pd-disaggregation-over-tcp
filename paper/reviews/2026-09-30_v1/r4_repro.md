## 5. 재현성 평가

강점:
- **네 단계가 결정적으로 재생성된다.** aggregate → safe_runs → (per_request 캐시) → make_figures_v1이다. CSV 두 개와 figures.json이 바이트 단위로 같다. 캐시도 bench.json 308개에서 새로 만들면 내용이 같다.
- **E8 계측 산출물이 원자료로 남아 있다.** 프록시 트레이스(jsonl), 디코드 서버 ITL 히스토그램 전후 스냅샷, ss 샘플, xfer 로그가 모두 있다.
- **E8 주장은 공개 스크립트 셋으로 모두 다시 나온다.** `stall_match.py`로 4/5 일치와 GC 25–40 ms가 나온다. `ss_parse.py`로 연결 4개와 몫이 나온다. `e8_summary.py`로 정지 제외 달성률이 나온다. 서버 측 113건은 히스토그램 차분으로 확인했다.
- 1차에서 CSV 밖에 있던 네트워크 수치가 대부분 로그 파서로 옮겨졌다.

제3자를 막는 것(우선순위순):
1. **[필수] GitHub 푸시 불가.** 457 MB 파일이 있고 추적 합계가 7.1 GB다. 원자료는 Zenodo 아카이브로 옮긴다. result.json에는 meta만 남긴다. 그러면 추적량은 약 절반으로 준다.
2. **[필수] README에 재현 명령을 적는다.**
   ```
   python3 harness/aggregate.py results/ -o results/all_runs.csv --slo chat=ttft:1000,tbt:50 --slo doc=ttft:3000,tbt:250
   python3 harness/safe_runs.py results/all_runs.csv -o results/safe_runs.csv
   uv run --with matplotlib python3 harness/make_figures_v1.py -o paper/figures_v1
   python3 harness/e8_summary.py results/E8
   ```
   aggregate.py의 기본 SLO를 논문 값으로 바꾸는 편이 더 안전하다. `make_figures_v1.py`는 캐시가 있으면 다시 만들지 않으므로 `--rebuild` 옵션을 넣는다.
3. **[필수] 계정 ID 정리**(HEAD와 이력 모두).
4. **[필수] 판정 근거 스크립트를 harness로 옮긴다**(⚠️ P3).
5. [권장] v1_ttft 값을 계산 코드로 바꾼다. 분석 환경을 고정하고(uv.lock), 도커 digest를 적는다. 런 매니페스트를 만든다. `xfer_stats`의 `glob`을 `sorted`로 바꾼다(SVG 결정성).
