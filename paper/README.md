# paper/

The technical report and everything needed to rebuild it.

| Path | What it is |
|---|---|
| `main.pdf` | Technical Report v1.0, the citable PDF. Built from `en/main.tex`. |
| `en/main.tex`, `en/refs.bib` | LaTeX source and bibliography of the English report. Built with [tectonic](https://tectonic-typesetting.github.io/). |
| `en/draft.md` | Markdown rendering of `en/main.tex`, generated by `tools/tex2md.py`. Do not edit by hand; regenerate it. |
| `ko/draft.md` | Korean rendering of the report, maintained by hand in sync with the English source. |
| `figures/` | Every figure as SVG and PDF, produced by `analysis/make_figures.py` (drawing library `analysis/fig_common.py`). Also `figures.json`, the numbers behind each figure as the script computed them, and `boundary.json`, the fitted parameters of the Section 6 step-time model written by `analysis/boundary_model.py`. `figures/png/` holds PNG copies used by the repository README. |
| `reviews/` | Four rounds of AI-assisted mock peer review of the English draft (v0, v1, v2, v4). Each round has five role reviews, a meta review, and the scripts the reviewers ran. The reviews are in Korean; each round's README starts with an English summary. |
| `tools/` | Scripts that turn the sources above into the markdown and HTML reading pages (see below). |

## Building

PDF, from the LaTeX source:

```bash
cd paper/en && tectonic main.tex && cp main.pdf ../main.pdf
```

English markdown, from the LaTeX source (run from the repository root):

```bash
python3 paper/tools/tex2md.py paper/en/main.tex -o paper/en/draft.md --bib paper/en/refs.bib
```

Standalone HTML reading pages with the figures inlined (the `markdown` package is the only dependency):

```bash
uv run --with markdown python3 paper/tools/build_draft_html.py paper/en/draft.md -o en.html \
    --lang en --fig-dir paper/figures --title "Technical Report v1.0" --meta "<span>v1.0</span>"
uv run --with markdown python3 paper/tools/build_draft_html.py paper/ko/draft.md -o ko.html \
    --lang ko --fig-dir paper/figures --title "기술 보고서 v1.0" --meta "<span>v1.0</span>"
```

Figures, when the analysis changes (see the repository README for the data they need):

```bash
uv run --with numpy python3 analysis/boundary_model.py --json paper/figures/boundary.json
uv run --with matplotlib python3 analysis/make_figures.py
```

## tools/

- `tex2md.py` converts `en/main.tex` to the markdown dialect the HTML builder reads. It handles only the LaTeX this report uses: sections, lists, figures, tabularx tables, display and inline math, numeric citations in order of first use, cross references, and footnotes. Figures become `<!-- FIG name | Figure N. caption -->` comments, where `name` is an SVG in `figures/`.
- `build_draft_html.py` renders a draft markdown file to one HTML page. Each `FIG` comment is replaced with the SVG, recoloured to CSS variables so the page follows the light and dark theme. `--lang` chooses the language of the page's own UI text only (table of contents label, footer); the body is the markdown as given, so `--lang ko` keeps Korean labels on the Korean page.
- `build_figure_page.py` builds a figure gallery from `ko/draft.md`, reusing the draft's captions so the two cannot drift. It is a companion to the Korean draft and its page text is Korean.

The committed reading pages are regenerated with explicit `--title` and `--meta`, so the defaults of `build_draft_html.py` are only fallbacks.
